# Easter Symbols Carousel

A modern, accessible, and responsive carousel showcasing traditional Easter symbols. Each card features an image, title, description, and a call-to-action link for more information.

## Features
- Seamless infinite carousel animation
- Responsive design for desktop and mobile
- Accessible markup and focus management
- Modern CSS with custom properties and gradients
- Easter-themed images and descriptions

## Usage
Open `index.html` in your browser to view the carousel. Customize images, text, or styles in `style.css` as needed.

## Files
- `index.html`: Main HTML file with carousel markup
- `style.css`: Modern CSS for layout, animation, and theming
